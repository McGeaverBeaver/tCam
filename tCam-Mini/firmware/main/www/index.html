Auto range tracks the coldest and hottest pixels in view, smoothed so the image does not flicker when something briefly enters the frame.
Raw saves the camera's own json frame, the same format the desktop application writes, so existing analysis tools still read it.
Every frame is about 53 KB of json. Slowing the interval is the single most effective way to keep a marginal WiFi link stable.
AGC gives a higher contrast picture but the pixels stop being temperatures, so the readouts above are disabled while it is on.
Polished metal is nearer 10–30%, painted or organic surfaces nearer 90–98%.
Also the access point name and the mDNS hostname.
Unchecked, the camera keeps broadcasting its own access point and you connect straight to it. Checked, it joins your network and is reachable at tcam-mini.local.
If the camera cannot join the network it falls back to its own access point, so a wrong password is recoverable without a cable.
